# 화면 디자인 체계

UI를 고칠 때의 기준. 에피소드 내용 규칙은 `docs/EPISODE_GUIDE.md`.

## 개념
기록보관소의 열람 사본. 인쇄된 문서는 철담즙 잉크(남흑색)로, **플레이어가 고르고 쓴 것은 모두 복사 연필(보라)**로 표시한다. 강조색은 **형광펜 노랑 하나**이며 글자색으로 쓰지 않고 바탕으로만 칠한다.

## 색 토큰 (`src/ui/styles.css`의 `:root`)
| 토큰 | 값 | 용도 |
|---|---|---|
| `--paper` | `#e6eae7` | 페이지 바탕 |
| `--paper-2` | `#dbe1dd` | 보고 패널, 지도 주변 |
| `--paper-3` | `#f0f3f1` | 입력란, 펼침 패널, 새 보고 |
| `--ink` | `#1f2733` | 본문, 선 |
| `--ink-2` | `#57616d` | 보조 글자 |
| `--rule` | `#c3cac6` | 구분선 |
| `--pencil` | `#5a3d8a` | 플레이어의 것: 선택, 이유, 남은 질문, 비교표의 "당신", "다름" |
| `--marker` | `#f2b530` | 강조 바탕만: 주 버튼, 지금 단계, 플레이어의 나라, "추정" 표시 |
| `--error` | `#8f2b2b` | 오류 문구 |

새 색을 더하지 않는다. 지도 SVG도 같은 값을 쓴다.

## 서체
- **Hahmlet**(세리프): 문서 본문, 제목.
- **IBM Plex Sans KR**: 조작 요소, 메타 정보, 세력 기호, 플레이어의 글씨(입력란).
- 대문자 라벨, 모노스페이스, 가운뎃점(·)으로 잇는 메타 문자열, 화살표(→) 붙인 버튼을 쓰지 않는다.

## 세력 기호
- 본문 속 기호(A, B …)는 산세리프 굵은 글자(`.ent`). 플레이어의 나라는 형광 바탕(`.ent.self`).
- 첫 언급 풀이(`.gloss`)는 보고·반론·선택지 목록 단위로 한 번.
- 공개 화면에서는 실명 + 원래 기호 첨자(`.ent.named`).

## 레이아웃
- 720px 미만: 한 칸. 단계 표시, 탐문 도구 막대(남은 질문·기호 풀이·결정하러 가기)가 위에 붙는다.
- 1024px 이상: **왼쪽 사건 레일(16.5rem, sticky) + 본문.** 레일: 사건 번호·제목, 세로 단계, 남은 질문, 기호 풀이, 관계도. 본문 안의 같은 도구는 숨긴다.
- 1280px 이상: 탐문(자문관 | 받은 보고), 결정(방침·세부 | 이유 sticky)을 두 칸으로.
- 본문 문단 폭은 36em 이하. 페이지 최대 폭 1440px.

## 움직임
- 사용자 행동에 대한 반응만: 새 보고·새 반론이 나타날 때 0.25초 페이드. 페이지 진입 연출, 카드 호버 효과는 넣지 않는다.
- `prefers-reduced-motion`이면 끈다.

## 접근성
- 터치 대상 44px 이상, `:focus-visible`은 보라 2px 외곽선.
- 그림은 `aria-label`/`alt`로 내용을 문장으로.
- 오류는 `role="alert"`, 동적 응답은 `aria-live="polite"`.
